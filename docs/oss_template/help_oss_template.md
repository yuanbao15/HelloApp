# 使用帮助（OSS 模板）

> 本应用需要若干系统权限才能稳定监听交警短信并在锁屏下及时响铃报警。
> 请按下面的步骤逐项开启，否则可能被系统后台杀进程 / 拦截通知从而影响使用。

## 一、必开权限清单

开启路径：**设置 → 应用管理 → 交警短信增强提醒 → 权限**

| 权限 | 用途 | 是否必须 |
| --- | --- | --- |
| 短信 | 读取短信内容，匹配关键词触发警报 | ✅ 必开 |
| 通知 | 弹出警报横幅、播放铃声 | ✅ 必开 |
| 自启动 | 应用被系统清理后能自动恢复监听 | ⚪可选 |
| 后台运行 | 锁屏后继续监听新短信 | ✅ 必开 |
| 电池优化（设为"不优化"）| 防止系统在锁屏后冻结进程 | ✅ 必开 |
| 读取联系人 | 号码归属地识别（可选） | ⚪ 可选 |

## 二、电源白名单（按厂商区分）

> 这是**最容易遗漏**的一项。多数手机厂商默认会"智能省电"——当应用长时间无前台活动时强制休眠，导致收不到新短信。

### 小米 / 红米（MIUI / HyperOS）

1. 设置 → 应用管理 → 交警短信增强提醒
2. 点击右上角 ⚙️ 或"省电策略"
3. 选择 **"无限制"** 或 **"不优化"**
4. 返回上一层，开启 **"自启动"** 开关
5. （可选）进入"神隐模式"白名单

![小米电源白名单](https://yuanbao-oss.oss-cn-shenzhen.aliyuncs.com/file/public/develop_resources/YB/HellloApp/yb_files/help_imgs/miui_battery.png)

### 华为 / 荣耀（EMUI / HarmonyOS）

1. 设置 → 应用 → 应用启动管理
2. 找到"交警短信增强提醒"
3. 关闭 **"自动管理"** 开关
4. 手动开启：**自启动**、**后台活动**、**关联启动** 三个开关

### OPPO / vivo（ColorOS / OriginOS）

1. 设置 → 电池 → 更多电池设置
2. 关闭 **"睡眠待机优化"**
3. 设置 → 应用管理 → 交警短信增强提醒 → 耗电管理
4. 选择 **"允许后台高耗电"** 或 **"不限制"**

## 三、短信权限详细设置

> 部分手机（小米 / 华为）对短信权限做了二次分级。

### 1. 授予短信权限

设置 → 应用管理 → 交警短信增强提醒 → 权限 → 短信 → **允许**

### 2. 设为默认短信应用（可选，仅小米/华为部分机型）

如果应用提示"请设为默认短信应用"：
1. 设置 → 应用 → 默认应用 → 短信应用
2. 选择 **"交警短信增强提醒"**

> ⚠️ **重要提示**：本应用**不会**真的替代你的默认短信应用，它只是临时被授予短信读取权限用于监听。

![短信权限设置](https://yuanbao-oss.oss-cn-shenzhen.aliyuncs.com/file/public/develop_resources/YB/HellloApp/yb_files/help_imgs/sms_permission.png)

## 四、通知权限详细设置

### 1. 开启通知

设置 → 应用管理 → 交警短信增强提醒 → 通知管理 → **允许通知**

### 2. 关键通知类别

开启以下几个类别（不同系统叫法略有差异）：

| 类别 | 作用 |
| --- | --- |
| 警报通知 | 高优先级横幅、响铃、震动 |
| 锁屏通知 | 锁屏下也能弹出 |
| 横幅通知 | 顶部下拉横幅 |
| 角标 | 应用图标上的数字角标 |

### 3. 不要被"专注模式 / 免打扰"拦截

- **勿扰模式**：把本应用加入"允许打扰"白名单
- **专注模式**：把本应用加入"允许通知"列表
- **会议模式**：临时关闭，避免错过警报

## 六、锁屏下显示通知

### MIUI / HyperOS
设置 → 通知 → 锁屏通知 → 选择 **"显示所有通知内容"**

### HarmonyOS
设置 → 通知 → 锁屏通知 → 开启 **"显示通知"**

### ColorOS / OriginOS
设置 → 通知与状态栏 → 锁屏通知 → 选择 **"显示所有通知"**

## 七、常见问题排查

### Q1：配置好了还是收不到警报？

按顺序排查：
1. ✅ 短信权限是否真正授予（不是"询问"状态）
2. ✅ 电源白名单是否设为"不优化"
3. ✅ 自启动开关是否开启
4. ✅ 应用内是否设置了**正确的触发号码**和**关键词**
5. ✅ 短信关键字是否包含中文逗号、全角符号等（建议用纯字母数字）

### Q2：响铃只响一次就停了？

部分系统（华为/小米）默认限制长音频后台播放。
- 解决 1：开启本应用的"媒体播放"权限
- 解决 2：进入电源白名单设为"无限制"
- 解决 3：关闭系统的"灭屏自动暂停后台活动"

### Q3：通知横幅不弹出？

- 检查是否被"悬浮窗权限"拦截
- 设置 → 应用 → 交警短信增强提醒 → 其他权限 → **显示悬浮窗** → 开启

### Q4：杀进程后不自动重启？

- 确认"自启动"开关已开启
- 部分机型需要额外开启"关联启动"或"全家桶启动"
