# 使用帮助文档

> 本应用需要若干系统权限才能稳定监听交警短信并在锁屏下及时响铃报警。
> 请按下面的步骤逐项开启，否则可能被系统后台杀进程 / 拦截通知从而影响使用。

## 一、必开权限清单

开启路径：**设置 → 应用管理 → 交警短信增强提醒 → 权限**

| 权限 | 用途 | 是否必须 |
| --- | --- | --- |
| 短信 | 读取短信内容，匹配关键词触发警报 | ✅ 必开 |
| 通知 | 弹出警报横幅、播放铃声 | ✅ 必开 |
| 自启动 | 应用被系统清理后能自动恢复监听 | ⚪ 可选 |
| 后台运行 | 锁屏后继续监听新短信 | ✅ 必开 |
| 电池优化（设为"无限制/不优化"） | 防止系统在锁屏后冻结进程 | ✅ 必开 |
| 读取联系人 | 号码归属地识别（可选） | ⚪ 可选 |



---

## 二、电源白名单（按厂商区分）

> 这是**最容易遗漏**的一项。多数手机厂商默认会"智能省电"——当应用长时间无前台活动时强制休眠，导致收不到新短信。

### 小米 / 红米（MIUI / HyperOS）

1. 设置 → 应用管理 → 交警短信增强提醒
2. 点击右上角 ⚙️ 或"省电策略"
3. 选择 **"无限制"** 或 **"不优化"**
4. 返回上一层，开启 **"自启动"** 开关（可选）

<img src="https://yuanbao-oss.oss-cn-shenzhen.aliyuncs.com/img/public_imgs/PicGo/202608112201119.jpg" alt="img" style="zoom: 50%;" />

### 华为 / 荣耀（EMUI / HarmonyOS）

1. 设置 → 应用 → 应用启动管理
2. 找到"交警短信增强提醒"
3. 关闭 **"自动管理"** 开关
4. 手动开启：**自启动**、**后台活动**、**关联启动** 三个开关

### OPPO / vivo（ColorOS / OriginOS）

1. 设置 → 电池 → 更多电池设置
2. 关闭 **"睡眠待机优化"**
3. 设置 → 应用管理 → 交警短信增强提醒 → 耗电管理
4. 选择 **"允许后台高耗电"** 或 **"不限制"**



下面将主要以小米手机为例进行讲解说明，其他品牌手机的对应入口需自行摸索。

## 四、应用内设置项说明

### 1、首页

- **总开关**：开启后，整个应用才会开启监听提醒，否则不会提醒。【重点】关闭后所有监听规则均不生效。
- **监听号码**：可按个人需求设置监听短信号码（如 `12123`）。需配合右侧开关启用「号码匹配」，启用后符合该号码的短信才会提醒，与关键词是**逻辑与**的关系（两个条件都要满足才提醒）。
- **关键词**：可按个人需求设置多个关键词来匹配短信内容（大小写不敏感）。支持添加/删除，至少保留一个。
  - **匹配逻辑**：
    - 逻辑或：任一关键词命中即提醒
    - 逻辑与：所有关键词全部命中才提醒
- **警报音效**：
  - 当前系统音量：显示手机当前媒体音量,可按音量键后再点「刷新」更新
  - 警报音量：滑块调节（0~100%），报警时会临时切换到该音量，结束后自动恢复原音量
  - 音效选择：简短铃声 / 警车警报，二选一。前者柔和提示效果有限，后者紧急警报🚨提示作用显著
  - 试听音效：点击试听当前所选音效（单次播放）
- **震动提醒**：开关。开启后警报时同步震动。
  - 震动时长：默认短震 / 10秒 / 30秒 / 60秒（当前设置震动最长不超过60s，避免震动时间过长影响震动马达寿命）
- **操作**：
  - 检查权限：申请/校验短信读取权限,被拒时引导去系统设置开启
  - 清空日志：清空页面显示的运行日志
  - 手动测试警报：模拟一条命中规则的短信,走完整提醒流程（不影响真实短信的去重）
- **运行日志**：实时显示监听、匹配、播放等过程。日志会自动落盘到 `fs://log/`（按天切分），并自动清理7天前的旧日志。

> 提醒触发后，会同时：推送通知栏消息 → 弹出警报对话框 → 循环播放警报铃声+震动，点击「我知道了」即停止。

### 2、统计页

按年度统计所有命中规则的警报记录（顶部可切换年份：当年及前两年）。

- **统计概览**：总警报次数、月平均次数、最高月次数、最近警报时间
- **风险分析**：最长连续天数、平均间隔（天）、近期趋势（上升/下降/稳定）、风险等级（高/中/低/安全）
- **行为模式**（点击可查看详情）：最频繁星期、最频繁时段、最频繁月份、预测下次时间
- **智能建议**：根据风险等级、连续天数、时间规律、趋势等自动生成提醒
- **图表**（点击柱子查看详情）：
  - 月度趋势（12个月）
  - 星期分布（周一~周日）
  - 时段分布（24小时,数据多时自动合并）
- **操作按钮**：
  - 导出数据：将当年记录导出为 JSON 文件
  - 分享统计：调用系统分享
  - 多选删除：批量勾选删除
  - 清空记录：清空当前年份记录
- **详细记录**：
  - 下拉刷新、增量加载（底部「加载更多」）
  - 点击单条：查看完整详情
  - 左滑：单条删除
  - 长按：进入多选模式

### 3、更多页

点击底部「更多」弹出菜单,包含以下功能：

- **关于应用**：从云端（OSS）拉取 `about.md` 渲染展示（含开发者公告、应用介绍）。右上角支持刷新、分享。
- **使用帮助**：从云端拉取 `help.md` 渲染展示（权限设置、电源白名单、短信/通知权限等图文教程）。在 OSS 上更新即可生效,无需发版。
- **检查更新**：对比云端 `version.json` 与本地版本,有新版可在线下载并调起系统安装器。
- **清除缓存**（二级菜单）：
  - 清除一般缓存：重置监听设置（号码/关键词/音量/音效等）到默认值，并清远程缓存和日志,**保留**消息记录
  - 清除消息记录：清空所有年份的警报记录,**保留**用户设置
  - 重置初始化：清空全部数据,恢复出厂状态（危险，需二次确认）
- **导出数据**：备份用户配置、警报记录、去重记录等为 JSON 文件，可分享或保存。
- **导入数据**：通过系统文件管理器选择备份文件，按规则合并去重导入（不覆盖现有设置），支持 APP 沙盒目录和 SD 卡公共目录。
- **打赏捐赠**：打开捐赠页面，支付宝/微信，如果觉得APP对你有帮助请给开发者助力。

> 整个应用不联网传输用户数据，云端仅用于拉取帮助/公告/版本信息；短信读取与数据分析全部在本地完成。
