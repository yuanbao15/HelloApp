## 1. 整体架构

### 1.1 技术栈

| 层 | 技术 |
|----|------|
| 平台 | APICloud（HTML/CSS/JS + 自定义原生模块） |
| UI 库 | AUI 2.0（[css/aui.2.0.css](css/aui.2.0.css)、[css/aui.css](css/aui.css)） |

| 持久化 | `api.setPrefs` / `api.getPrefs`（key-value 存储）+ `localStorage`（少量去重标记） |

APICloud 平台规则：官方模块 + 已上传到 APICloud 编译环境的自定义模块，可直接在 JS 中 `require`，无需在 `config.xml` 中声明 `<feature>`。本功能涉及的此类模块有：

### 3.4 业务主流程

#### 3.4.1 启动监听

```
[apiready]
   ├─ checkSMSPermission()              # 请求短信读取权限
   ├─ initSMSListenerModule()           # require 三个自定义模块
   ├─ initUI()                          # 加载 prefs，恢复开关/号码/关键词/逻辑
   ├─ initAcc5Util()                    # require acc5Util
   └─ loadAlertRecords()                # 加载 alertRecords_当前年

[smsSwitch.change → 开启]
   ├─ startSMSListener()
   │    ├─ smsListenerModule.registerSmsListener(callback)
   │    └─ startAlive() → moduleProcessAlive.startAlive()
   ├─ enableSections()                  # UI 启用关键词/逻辑区域
   └─ api.setPrefs({ key:'isListening', value:'true' })
```

#### 3.4.2 收到短信 → processSMS 流程

📍 [processSMS](html/test_SMS_monitor.html#L604-L687)

```
[ smsListener 回调 ]
   │
   ▼
[ 去重检测 - 双重检查 ]
   ├─ 检查 localStorage.recentSMS（按天去重）
   ├─ 检查 alertRecords 中是否有当天同号码同内容
   └─ 若重复 → 直接 return
   
   ▼
[ 号码过滤 ]
   └─ 若 enableNumberMatch && !sms.tel.contains(targetNumber) → return
   
   ▼
[ 关键词匹配 ]
   └─ checkContentMatch(sms.content)
       ├─ or 模式：任一关键词匹配
       └─ and 模式：所有非空关键词都匹配
   
   ▼
[ 命中后触发 ]
   ├─ showNotification('【紧急】交警短信', sms.content)   # 通知栏
   ├─ recordAlert(sms)                                    # 记录数据
   └─ playAlert(sms.content)                              # 播放音效
```

#### 3.4.3 playAlert 警报播放

📍 [playAlert](html/test_SMS_monitor.html#L708-L755) + [startContinuousPlay](html/test_SMS_monitor.html#L758-L791)

```
playAlert(smsContent)
   │
   ├─ isPlaying ? 先 stopPlay()
   ├─ isPlaying = true
   │
   ├─ saveAndSetVolume(alertVolume, callback)    # 保存当前音量 + 设置警报音量
   │   └─ 回调成功 → startContinuousPlay(audioPath, smsContent)
   │
   └─ showAlertDialog(smsContent)                # 弹窗"我知道了"

startContinuousPlay(audioPath, smsContent)
   │
   ├─ api.startPlay({path: audioPath}, callback)
   │
   ├─ 播放完成 → isPlaying ? 递归继续播放 (setTimeout 500ms)
   └─ 用户停止 / 对话框关闭 → api.stopPlay() + restoreOriginalVolume()
```

> ⚠️ 连续播放靠 `setTimeout` 递归实现，无最大次数限制，依赖用户主动停止。

#### 3.4.4 警报记录 recordAlert

📍 [recordAlert](html/test_SMS_monitor.html#L1312-L1354)

```js
record = {
    id: Date.now(),                      // ⚠️ 并发风险：详见 02-问题清单 M7
```

### 3.5 互斥锁机制

📍 [html/test_SMS_monitor.html:230-285](html/test_SMS_monitor.html#L230-L285)

```js
window.__SMS_MONITOR_INSTANCE_ID = ...   // 实例 ID
window.__SMS_MONITOR_LOCK = false         // 互斥锁

apiready 时：
   if (__SMS_MONITOR_LOCK) return;       // 已有实例则不再注册监听
```

设计目的：防止多个 frame 同时注册 `registerSmsListener` 触发重复回调。

### 4.4 统计计算

| 指标 | 函数 | 算法 |
|------|------|------|

| 最高月 | 同上 | 遍历 12 月份桶取 max |
